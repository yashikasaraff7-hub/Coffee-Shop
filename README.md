# Coffee-Shop
Yashika’s Coffee Shop is a simple and aesthetic static website designed to represent a cozy coffee shop.
The website provides basic information about the shop, including:
	•	About section
	•	Specialties
	•	Menu items
	•	Navigation links
	•	A banner section with an external link

The main purpose of this project is to create a visually pleasing and structured webpage using only HTML and CSS. It focuses on layout design, section organization, and basic styling techniques.

This project demonstrates how a simple business website can be built using front-end technologies without any backend.
